# Realistic user prompt used to exercise website-design-cloner

“I own tamver.eu. Extract its observable design system and convert it into an implementation-ready design kit for a sister research site. Preserve the TAMVER visual language—wordmark spacing, dark olive/black surfaces, light editorial sections, thin typography, hairline borders, warm globe-like illumination and restrained motion—but do not copy protected photos or page copy. Produce normalized tokens, CSS variables, Tailwind/shadcn mappings, starter React components, responsive notes and coding-agent prompts. Then apply the kit to TAMVER Research while preserving the interactive Decision Evidence Motion Crystal.”

## Coding contract
Use the generated design kit as source of truth. Never invent a visual value when a mapped token exists. Preserve observed/inferred provenance. Research additions may extend the system only if they keep TAMVER hierarchy and visual grammar.
