# shadcn mapping

TAMVER should not inherit default rounded SaaS styling.

- `--background` → `--tamver-black`
- `--foreground` → `--tamver-white`
- `--card` → transparent/olive-black surface
- `--border` → `--tamver-line-soft`
- `--primary` → `--tamver-amber`
- `--destructive` → `--tamver-alert`
- radius → `0rem` for editorial/Research surfaces; only circular graph nodes remain circular.
- Buttons: hairline border, uppercase 10–11px, wide tracking; avoid filled blue defaults.
- Dialog/Drawer: dark olive-black + backdrop blur + amber hairline focus.
