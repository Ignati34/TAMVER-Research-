# Coding prompt — TAMVER Research visual consistency

Use `src/styles/tamver-tokens.css` as the only source of visual constants.
Do not introduce blue/cyan SaaS gradients, generic rounded cards, thick shadows, or default shadcn styling.
Maintain TAMVER's observable visual DNA: near-black / olive photographic surfaces, off-white editorial contrast, thin ivory typography, hairline borders, restrained amber energy lighting, generous negative space, square geometry.
Research-specific exception: the faceted Decision Evidence Crystal is allowed as the central interactive object. Its ambient edges are warm ivory/amber. Hover previews are subtle. Click/touch activation flashes the selected node red for ~1.7 s and launches a single propagation wave through connected crystal edges before returning to ambient state.
